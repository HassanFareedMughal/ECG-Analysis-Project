# ECG Analysis Project

![ECG Analysis Demo](results/ecg_plot.png)

## Project Description
MATLAB implementation of ECG signal processing using:
- Bandpass filtering (0.5-40 Hz)
- 5-level wavelet decomposition (Symlet4)
- R-peak detection algorithm
- Heart rate variability analysis

## Features
- MIT-BIH Arrhythmia Database compatibility
- Interactive visualization
- Modular code structure

## Requirements
- MATLAB R2020b+
- Signal Processing Toolbox
- Wavelet Toolbox
